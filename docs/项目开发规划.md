# Psychopomp 项目开发规划

## 项目概述

Psychopomp 是基于 Cocos Creator 3.x 开发的解谜/冒险游戏，采用 Manager 单例模式架构。

---

## 一、已完成的核心系统

### 1.1 Manager 架构

| Manager | 职责 | 状态 |
|---------|------|------|
| GameManager | 游戏状态机、流程控制 | ✅ |
| DataManager | 存档、flag、物品管理 | ✅ |
| DialogManager | 对话播放控制 | ✅ |
| InventoryManager | 物品栏状态管理 | ✅ |
| InteractableManager | 交互点逻辑处理 | ✅ |
| SceneViewManager | 场景加载、预加载（Map） | ✅ |
| UIManager | UI 层级控制 | ✅ |
| ResourceManager | 资源配置加载 | ✅ |

### 1.2 交互点系统

- 支持 `setFlags`、`pickItem`、`switchScene`、`data.dialogueId`
- 发出 `INTERACTABLE_TRIGGERED` 事件

### 1.3 场景预加载系统

- 使用 Map 存储多个预加载场景
- 支持 `preloadScene`、`switchToScene`
- `scenes.json` 配置 `preloadNext` 邻接场景

### 1.4 物品与 Flag 系统

- `ADD_ITEM_REQUEST` 事件 → 拾取物品
- `SET_FLAG_REQUEST` 事件 → 设置 flag
- `FLAG_CHANGED` 事件 → flag 变化通知

### 1.5 UI 层级结构

```
Canvas
├── Managers (常驻)
├── sceneContainer (游戏场景)
└── UI
    ├── fullscreenLayer
    │   ├── mainMenu
    │   ├── gameOverScreen
    │   ├── videoPlayer
    │   └── IntroCutscene（待完成）
    └── gameLayer
        ├── inventoryPanel
        ├── menuPanel
        └── dialogPanel
```

### 2.1 开场演出系统（进行中）

**目标**：视频结束后、正式游戏前的交互演出

**方案**：fullscreenLayer 演出 Prefab

**节点结构**：
```
fullscreenLayer
└── IntroCutscene（Pref

ab）
    └── Container
        └── Background
```

**脚本**：`IntroCutscene.ts`（已创建）

**流程**：
```
开始游戏
    ↓
INTRO_START（播放视频）
    ↓
INTRO_COMPLETE
    ↓
showIntroCutscene()（显示 IntroCutscene）
    ↓
动画（晃动+放大）
    ↓
等待点击
    ↓
DialogManager.showDialogue()（播放对话）
    ↓
DIALOGUE_END
    ↓
INTRO_CUTSCENE_COMPLETE
    ↓
hideIntroCutscene() + 进入游戏
```

**需配置**：
- `scenes.json` 中添加 `HAS_INTRO_CUTSCENE` flag
- 对话数据 `intro_cutscene`
- 背景图数组 `bgStages`

### 2.2 贴图状态持久化

**需求**：交互点改变贴图后，切换场景/重进存档仍保持状态

**方案**：利用现有 flag 系统

**场景脚本对接**：
```typescript
onLoad() {
    // 初始化贴图状态
    if (DataManager.instance.getBool("PILLOW_MOVED")) {
        this.pillowSprite.spriteFrame = this.movedFrame;
    }

    // 监听变化
    director.on("FLAG_CHANGED", this._onFlagChanged, this);
}

private _onFlagChanged(data: { name: string, value: boolean }) {
    if (data.name === "PILLOW_MOVED") {
        this.pillowSprite.spriteFrame = data.value
            ? this.movedFrame
            : this.normalFrame;
    }
}
```

## 三、事件通信汇总

### 核心事件

| 事件 | 发出方 | 接收方 | 用途 |
|------|--------|--------|------|
| `START_NEW_GAME` | UI按钮 | GameManager | 开始新游戏 |
| `INTRO_START` | GameManager | UIManager | 播放开场视频 |
| `INTRO_COMPLETE` | UIManager | GameManager | 视频结束 |
| `INTRO_CUTSCENE_COMPLETE` | IntroCutscene | GameManager | 演出结束 |
| `LOAD_GAME` | UI按钮 | GameManager | 加载存档 |
| `PAUSE_GAME` / `RESUME_GAME` | UI | GameManager | 暂停/恢复 |
| `QUIT_TO_MENU` | UI | GameManager | 退出到主菜单 |
| `INTERACTABLE_CLICK` | Interactable | InteractableManager | 点击交互点 |
| `INTERACTABLE_TRIGGERED` | InteractableManager | GameManager/场景 | 交互结果 |
| `SET_FLAG_REQUEST` | 交互点/场景 | InteractableManager | 设置flag |
| `ADD_ITEM_REQUEST` | 交互点/场景 | InteractableManager | 拾取物品 |
| `FLAG_CHANGED` | DataManager | 场景脚本 | flag变化通知 |
| `DIALOGUE_REQUEST` | 场景 | DialogManager | 请求播放对话 |
| `DIALOGUE_START` | DialogManager | DialogPanel | 对话开始 |
| `DIALOGUE_LINE` | DialogManager | DialogPanel/场景 | 对话行 |
| `DIALOGUE_END` | DialogManager | DialogPanel/场景 | 对话结束 |
| `SCENE_READY` | SceneViewManager | GameManager | 场景加载完成 |
| `SCENE_SWITCH_START` | InteractableManager | - | 场景切换开始 |
| `SCENE_SWITCH_COMPLETE` | SceneViewManager | - | 场景切换完成 |

## 五、开发规范

### 5.1 脚本规范

- 使用 `@ccclass`、`@property` 装饰器
- `protected onLoad()` / `protected start()` / `protected onEnable()` / `protected onDisable()` / `protected onDestroy()`
- `director.on` 在 `onEnable` 注册，`director.off` 在 `onDisable` 注销
- 事件处理函数使用 `_on` 前缀

### 5.2 场景 Prefab 结构

```
scene_xxx.prefab
├── Background
├── Midground
│   └── Interactables
│       └── [各交互点]
├── Popups（场景自管理）
└── Foreground
```

### 5.3 交互点配置

```json
{
    "interactables": [{
        "id": "door",
        "states": [{
            "result": {
                "code": "SUCCESS",
                "setFlags": [{ "name": "DOOR_OPENED", "value": true }],
                "switchScene": "scene_hall"
            }
        }]
    }]
}
```
