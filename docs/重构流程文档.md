# Psychopomp 重构流程文档

## 一、重构顺序与依赖关系

### 重构顺序（按依赖从低到高）

| 顺序 | 脚本 | 依赖 | 主要修改 |
|------|------|------|----------|
| 1 | DataManager | 无 | startNewGame() 不立即保存 |
| 2 | ResourceManager | 无 | 清理无用代码 |
| 3 | InventoryManager | DataManager | 物品消耗同步选中状态 |
| 4 | DialogManager | DataManager | 监听 DIALOG_NEXT，添加校验 |
| 5 | InteractableManager | DataManager, InventoryManager, DialogManager, SceneViewManager | 自动切换场景，添加 ADD_ITEM_REQUEST |
| 6 | SceneViewManager | DataManager, ResourceManager | 修复空场景、预加载多场景 |
| 7 | UIManager | 全部 | 修复事件名称、层级管理 |
| 8 | GameManager | 全部 | 重构游戏流程 |

#### 2.6.3 预加载多场景（使用 Map）

```typescript
private _preloadedSceneMap: Map<string, Node> = new Map();

public preloadNextScenes(): void {
    const config = DataManager.instance.getSceneConfig(this._currentSceneId);
    const preloadList = config?.preloadNext || [];

    this._preloadedSceneMap.clear();  // 清空旧的

    preloadList.forEach((sceneId: string) => {
        this.preloadSceneForSwitch(sceneId);
    });
}

public preloadSceneForSwitch(sceneId: string): void {
    if (this._preloadedSceneMap.has(sceneId)) return;

    ResourceManager.instance.loadScene(sceneId).then((prefab) => {
        const node = instantiate(prefab);
        node.name = sceneId;
        this._preloadedSceneMap.set(sceneId, node);
    });
}

public switchToScene(sceneId: string, transitionType: string = "fade"): void {
    if (this._transitioning) return;
    if (this._currentSceneId === sceneId) return;

    this._transitioning = true;
    director.emit("SCENE_SWITCH_START", sceneId);

    if (!this._preloadedSceneMap.has(sceneId)) {
        // 未预加载，同步加载
        ResourceManager.instance.loadScene(sceneId).then((prefab) => {
            this._completeSwitch(sceneId, instantiate(prefab), transitionType);
        });
    } else {
        // 已预加载
        const node = this._preloadedSceneMap.get(sceneId);
        this._completeSwitch(sceneId, node, transitionType);
    }
}
```

### 3.1 DialogPanel（对话框面板）

**监听事件**：

```typescript
// 显示对话
director.on("DIALOGUE_START", this._onDialogueStart, this);

// 显示对话行
director.on("DIALOGUE_LINE", this._onDialogueLine, this);

// 隐藏对话
director.on("DIALOGUE_END", this._onDialogueEnd, this);

// 点击时发出 DIALOG_NEXT
director.emit("DIALOGUE_NEXT");
```

**示例**：

```typescript
import { _decorator, Component, director } from 'cc';

@ccclass('DialogPanel')
export class DialogPanel extends Component {
    onLoad() {
        director.on("DIALOGUE_START", this._onDialogueStart, this);
        director.on("DIALOGUE_LINE", this._onDialogueLine, this);
        director.on("DIALOGUE_END", this._onDialogueEnd, this);
    }

    private _onDialogueStart(): void {
        this.node.active = true;
    }

    private _onDialogueLine(data: { text: string; index: number; total: number }): void {
        // 显示对话文本
        this.showText(data.text);
    }

    private _onDialogueEnd(): void {
        this.node.active = false;
    }

    onDialogueClick() {
        director.emit("DIALOG_NEXT");
    }

    onDestroy() {
        director.off("DIALOGUE_START", this._onDialogueStart, this);
        director.off("DIALOGUE_LINE", this._onDialogueLine, this);
        director.off("DIALOGUE_END", this._onDialogueEnd, this);
    }
}
```
