# 合并后场景开发文档

本文档描述重构后项目的整体节点层级结构和开发规范。

---

## 整体节点层级结构

```
Project Canvas (场景根节点)
│
├── UI 层级
│   └── Canvas
│       │
│       ├── UIManager          ← 挂载 UIManager.ts
│       │   └── (绑定所有 UI 节点)
│       │
│       ├── fullscreenLayer    ← 全屏内容层（视频、开场、结局）
│       │   ├── videoPlayer
│       │   ├── introCutscene
│       │   └── mainMenu
│       │
│       ├── gameLayer          ← 游戏内容层
│       │   ├── sceneContainer ← 场景容器（可选）
│       │   ├── inventoryPanel
│       │   ├── menuPanel
│       │   ├── dialogPanel
│       │   └── pauseMenu / gameOverScreen
│       │
│       └── sceneOverlay       ← 场景遮罩/过渡（可选）
│
├── Manager 层级
│   └── Managers
│       ├── GameManager         ← 挂载 GameManager.ts
│       ├── DataManager         ← 挂载 DataManager.ts
│       ├── ResourceManager      ← 挂载 ResourceManager.ts
│       ├── SceneViewManager    ← 挂载 SceneViewManager.ts
│       ├── DialogManager       ← 挂载 DialogManager.ts
│       ├── InventoryManager    ← 挂载 InventoryManager.ts
│       └── InteractableManager ← 挂载 InteractableManager.ts
│
└── Scene 场景节点（运行时动态创建）
    └── 由 SceneViewManager 创建和管理
        └── SceneViewManager._currentSceneNode
            └── [场景 Prefab 实例]
```

| 属性名 | 类型 | 说明 |

| fullscreenLayer | Node | 全屏层根节点 |
| gameLayer | Node | 游戏层根节点 |

## UI 层级说明

### fullscreenLayer（全屏层）

显示此层时 `gameLayer` 应隐藏。用于：
- 开场视频播放
- 开场动画/对话
- 结局动画
- 主菜单

### gameLayer（游戏层）

显示游戏内容时使用。包含：
- `sceneContainer`：场景节点容器（可选）
- `inventoryPanel`：背包 UI
- `menuPanel`：游戏内菜单
- `dialogPanel`：对话框
- `pauseMenu`：暂停菜单（可叠加）
- `gameOverScreen`：结束画面（可叠加）

### 切换规则

| 场景 | fullscreenLayer | gameLayer |
|------|----------------|-----------|
| 主菜单 | 显示 | 隐藏 |
| 开场动画 | 显示 | 隐藏 |
| 开场对话 | 显示 | 隐藏 |
| 正常游戏 | 隐藏 | 显示 |
| 暂停菜单 | 叠加显示 | 保持显示 |
| 结局动画 | 显示 | 隐藏 |

## SceneViewManager 场景管理机制

### 节点创建

```
start()
  └── initializeSceneNodes()
        └── 创建 _currentSceneNode（名为 "CurrentScene" 的空节点）
            └── 父节点 = sceneContainer ?? UIManager.sceneContainer ?? this.node
```

### 场景加载

```
loadScene(sceneId)
  ├── _clearAllScenes()  // 清除当前场景
  ├── ResourceManager.loadScene(sceneId)  // 加载 Prefab
  ├── instantiate(prefab)  // 实例化
  └── this._currentSceneNode.addChild(node)  // 添加到节点
        └── 发送 SCENE_READY 事件
```

### 场景切换

```
switchToScene(sceneId)
  ├── _transitioning = true  // 防重入
  ├── 发送 SCENE_SWITCH_START 事件
  ├── 从 _preloadedSceneMap 查找预加载场景
  │   └── 有 → _doSwitch(sceneId, node)
  │   └── 无 → ResourceManager.loadScene() → _doSwitch()
  │
  └── _doSwitch(sceneId, node)
        ├── _clearCurrentScene()
        ├── node.parent = _currentSceneNode
        ├── 发送 SCENE_SWITCH_COMPLETE 事件
        ├── 发送 SCENE_READY 事件（触发自动存档）
        └── _transitioning = false
```

### 预加载机制

```
preloadNextScenes()
  └── 从当前场景配置读取 preloadNext 列表
      └── 遍历调用 preloadSceneForSwitch(sceneId)
            └── 加载到 _preloadedSceneMap（不显示）
```

## 事件驱动架构

### 核心事件流

```
游戏启动
  └── GameManager.initializeGame()
        └── DataManager.loadGame("auto_save")
              └── 有存档 → GameManager._resumeGame()
              └── 无存档 → 显示主菜单

开始新游戏
  └── START_NEW_GAME 事件
        └── GameManager._onStartNewGame()
              └── DataManager.startNewGame()
              └── INTRO_START 事件
                    └── UI 播放开场动画
                          └── INTRO_COMPLETE 事件
                                └── GameManager._onIntroComplete()
                                      └── 检查 HAS_INTRO_CUTSCENE
                                            ├── 有 → showIntroCutscene()
                                            │         └── INTRO_CUTSCENE_COMPLETE
                                            └── 无 → setIntroPlayed(true)
                                                      └── _enterGame()

场景切换
  └── InteractableManager.handleClick()
        └── 检测到 switchScene
              └── SceneViewManager.switchToScene()
                    └── SCENE_SWITCH_COMPLETE
                          └── SCENE_READY
                                └── GameManager._onSceneReady()
                                      └── 自动存档
```

| 事件名 | 发送方 | 接收方 | 说明 |

## 场景配置格式

在 `assets/resources/data/scenes.json` 中配置：

```json
{
  "scene_id": {
    "name": "场景名称",
    "preloadNext": ["next_scene_id_1", "next_scene_id_2"],
    "interactables": [
      {
        "id": "interactable_1",
        "states": [
          {
            "id": "default",
            "condition": {
              "flag": "FLAG_NAME",
              "flagValue": true
            },
            "result": {
              "setFlags": [{ "name": "flag_name", "value": true }],
              "pickItem": "item_id",
              "switchScene": "target_scene_id",
              "code": "custom_code",
              "data": { "dialogueId": "dialogue_xxx" }
            }
          }
        ]
      }
    ]
  }
}
```

## 开发注意事项

1. **不要在 Manager 中直接操作 UI**：Manager 通过事件与 UI 通信
2. **场景节点由 SceneViewManager 管理**：不要手动创建或销毁场景节点
3. **使用事件驱动流程**：避免直接调用 Manager 方法
4. **存档自动触发**：场景就绪时自动保存，无需手动调用
5. **UIManager 只负责显隐**：具体的 UI 逻辑由各自的 Panel 组件处理
