# 游戏流程与存档逻辑梳理

## 一、当前流程分析

### 1.1 正常新游戏流程

```
START_NEW_GAME
    ↓
_onStartNewGame()
    ├── HIDE_MAIN_MENU
    ├── startNewGame() → 初始化 _saveData { currentScene: "", HAS_INTRO_CUTSCENE: true }
    └── INTRO_START
            ↓
    UIManager.playVideo()
            ↓
    视频播放中... (fullscreenLayer.active = true)
            ↓
    视频结束 → onVideoEnded() → INTRO_VIDEO_COMPLETE
            ↓
_onIntroVideoComplete()
    ├── 检查 HAS_INTRO_CUTSCENE
    └── true → showIntroCutscene()
            ↓
    对话结束 → DIALOGUE_END → _onDialogueEnd() → INTRO_COMPLETE
            ↓
_onIntroComplete()
    ├── hideIntroCutscene()
    ├── showGameUI() ← 游戏 UI 显示
    ├── setCurrentScene("scene_bedroom")
    └── _enterGame() → loadScene("scene_bedroom")
```

### 1.2 继续游戏流程（当前实现）

```
LOAD_GAME { slotId: "auto_save" }
    ↓
_onLoadGame()
    ├── HIDE_MAIN_MENU
    ├── loadGame("auto_save")
    │   └── 成功 → _resumeGame()
    │       └── 失败（无存档） → 什么也不做！用户留在主菜单
    │
    └── 不管 loadGame 结果如何，都没有处理无存档的情况
```

### 1.3 回到主界面流程

```
QUIT_TO_MENU / SHOW_MAIN_MENU
    ↓
_onQuitToMenu()
    └── SHOW_MAIN_MENU → showMainMenu()
            ↓
UIManager.showMainMenu()
    └── showFullscreenUI()
        ├── fullscreenLayer.active = true
        └── gameLayer.active = false
```

## 二、问题根因分析

### 问题1：无存档时"继续游戏"行为异常

**现象**：没有存档时点击"继续游戏"，会直接进入游戏场景跳过开场动画

**分析**：
查看 `_onLoadGame` 代码：
```typescript
private _onLoadGame(data: { slotId: string }): void {
    director.emit("HIDE_MAIN_MENU");
    if (data?.slotId && DataManager.instance.loadGame(data.slotId)) {
        this._resumeGame();
    }
    // ❌ 没有 else 分支！loadGame 返回 false 时什么也不做
}
```

**根因**：当 `loadGame()` 返回 `false`（无存档）时，代码没有任何处理，用户应该看到主菜单但实际行为异常。

---

### 问题2：先"继续游戏"再"新游戏"时 UI 错误唤起

**现象**：
- 正常点击"新游戏"→ 视频播放正常
- 先"继续游戏"再"新游戏"→ 视频播放时 UI（gameLayer）被错误唤起

**分析**：
查看 `showGameUI()` 代码：
```typescript
public showGameUI(): void {
    if (this.gameLayer) {
        this.gameLayer.active = true;  // ❌ 只激活 gameLayer，没有隐藏其他层
    }
    if (this.fullscreenLayer) {
        this.fullscreenLayer.active = false;
    }
}
```

问题在于 `showGameUI()` 只处理 `gameLayer` 和 `fullscreenLayer`，但 **不处理 `videoPlayer`**。

如果"继续游戏"流程中 `videoPlayer` 被激活（播放了残留视频），而"新游戏"流程中：
1. `INTRO_START` → `playVideo()` → `videoPlayer.active = true`（但 videoPlayer 可能已经在活跃状态）
2. 如果 `videoPlayer` 有残留状态，可能导致 `gameLayer` 被错误显示

**根因**：`playVideo()` 不清除旧状态，且 `showGameUI()` 不处理 `videoPlayer` 的隐藏。

---

### 问题3：存档功能无效

**现象**：无论有无存档，点击"继续游戏"都会跳过开场动画进入卧室场景

**分析**：
这与问题1相关。如果 `_onLoadGame` 在无存档时"什么也不做"，用户应该留在主菜单。但如果实际进入了卧室场景，说明：

1. 可能是 `loadGame()` 在无存档时错误返回了 `true`
2. 或者有其他代码路径触发了进入游戏的逻辑

查看 `loadGame()` 代码：
```typescript
public loadGame(slotId: string): boolean {
    const key = this._getStorageKey(slotId);
    const jsonStr = sys.localStorage.getItem(key);

    if (!jsonStr || jsonStr === "") {
        console.log(`[DataManager] 没有找到存档: ${slotId}`);
        return false;  // ✅ 正确返回 false
    }
    // ... 解析并加载存档
    return true;
}
```

`loadGame()` 逻辑看起来正确。但问题可能在于 **`hasSave()` 方法**：

```typescript
public hasSave(slotId: string): boolean {
    return this.getSaveSlotInfo(slotId).hasSave;
}
```

这个方法可能没有被正确使用来检查存档是否存在。

## 三、修复方案

### 修复1：完善 _onLoadGame 的无存档处理

**文件**：`GameManager.ts`

```typescript
private _onLoadGame(data: { slotId: string }): void {
    director.emit("HIDE_MAIN_MENU");

    if (data?.slotId && DataManager.instance.loadGame(data.slotId)) {
        // 有存档，正常恢复游戏
        this._resumeGame();
    } else {
        // 无存档，执行新游戏逻辑
        console.log("[GameManager] 没有找到存档，开始新游戏");
        DataManager.instance.startNewGame();
        director.emit("INTRO_START");
    }
}
```

### 修复2：完善 playVideo 清除旧状态

**文件**：`UIManager.ts`

```typescript
public playVideo(videoId: string): void {
    // 先清除旧状态
    this.hideVideoPlayer();

    this.showFullscreenUI();
    if (this.videoPlayer) {
        this.videoPlayer.active = true;
        director.emit("VIDEO_PLAY", videoId);
    }
}
```

### 修复3：完善 showGameUI 隐藏所有相关层

**文件**：`UIManager.ts`

```typescript
public showGameUI(): void {
    // 隐藏所有 fullscreen 层的内容
    if (this.fullscreenLayer) {
        this.fullscreenLayer.active = false;
    }
    if (this.videoPlayer) {
        this.videoPlayer.active = false;
    }
    if (this.introCutscene) {
        this.introCutscene.active = false;
    }

    // 显示游戏层
    if (this.gameLayer) {
        this.gameLayer.active = true;
    }
}
```

### 修复4：确保 ResumeGame_Button 正确处理无存档情况

**文件**：`ResumeGame_Button.ts`

当前代码（有问题）：
```typescript
director.emit("LOAD_GAME", { slotId: "auto_save" });
```

这会导致无存档时 `_onLoadGame` 什么都不做。应该修改 `_onLoadGame` 来处理无存档情况（见修复1）。

## 四、完整事件流程图（修复后）

### 新游戏流程
```
START_NEW_GAME
    ↓
_onStartNewGame()
    ├── HIDE_MAIN_MENU
    ├── startNewGame() → 初始化数据
    └── INTRO_START
            ↓
    playVideo() → showFullscreenUI() + videoPlayer.active = true
            ↓
    视频结束 → INTRO_VIDEO_COMPLETE
            ↓
    showIntroCutscene()
            ↓
    对话结束 → INTRO_COMPLETE
            ↓
_onIntroComplete()
    ├── hideIntroCutscene()
    ├── showGameUI() → gameLayer.active = true, fullscreenLayer.active = false
    ├── setCurrentScene("scene_bedroom")
    └── _enterGame()
```

### 继续游戏流程（修复后）

**有存档时**：
```
LOAD_GAME { slotId: "auto_save" }
    ↓
_onLoadGame()
    ├── HIDE_MAIN_MENU
    ├── loadGame() → true
    └── _resumeGame()
            ↓
    检查 introPlayed / endingPlayed
    └── 进入对应流程
```

**无存档时**：
```
LOAD_GAME { slotId: "auto_save" }
    ↓
_onLoadGame()
    ├── HIDE_MAIN_MENU
    ├── loadGame() → false
    └── startNewGame() + INTRO_START
            ↓
    进入新游戏流程
```
